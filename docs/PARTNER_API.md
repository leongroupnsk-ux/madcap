# Партнёрский API поставщика (v1)

API для учётной системы поставщика (1С, МойСклад, свой склад): остатки и цены по SKU, отправления и их подтверждение.
Ключи создаёт **владелец** кабинета: «Настройки → Ключи API». Ключ показывается один раз; в базе хранится только SHA-256.
Короткая подсказка — в кабинете, `/supplier/api`.

## Подключение

- Адрес: `https://<домен>/api/partner/v1` (в dev — `http://localhost:4100/api/partner/v1`).
- Аутентификация: заголовок `Authorization: Bearer ak_…`. Без ключа или с отозванным — `401`, кабинет заблокирован — `403`.
- Формат — JSON, кодировка UTF-8. Цены — в рублях (до двух знаков после запятой), остатки — целые штуки.
- Лимит: **120 запросов в минуту на ключ** (`PARTNER_API_RPM`). Заголовки `X-RateLimit-Limit` и `X-RateLimit-Remaining`;
  сверх лимита — `429` и `Retry-After` (секунды).
- Ключ видит только данные своего поставщика: чужие SKU попадают в `notFound`, чужие отправления — `404`.
- Каждый запрос на изменение пишется в журнал действий (`partner.stock`, `partner.prices`, подтверждение — `shipment.confirmed` с `via: partner_api`).
- Ошибки валидации — `400` вида `{ "message": "Проверьте поля формы", "errors": { "items.3.stock": "остаток не меньше 0" } }`.

## Остатки

`PUT /stock` — до 1000 позиций за запрос, SKU в пачке не повторяются.

```bash
curl -X PUT https://example.ru/api/partner/v1/stock \
  -H "Authorization: Bearer $AESCULAP_KEY" -H "Content-Type: application/json" \
  -d '{"items":[{"sku":"MT-1101-M","stock":12},{"sku":"MT-1101-L","stock":0}]}'
```

```json
{ "received": 2, "updated": 1, "unchanged": 1, "notFound": [] }
```

Остаток задаётся абсолютным числом и применяется сразу (без модерации). Если остаток вырос с нуля — подписчики
«Сообщить о поступлении» получают письмо; витрина обновляется сразу (сброс кэша каталога). Позиции, которых нет в запросе, не меняются.
Если один SKU есть у нескольких ваших товаров, обновляются все.

## Цены

`PUT /prices` — до 1000 позиций.

```json
{ "items": [ { "sku": "MT-1101-M", "price": 4590, "oldPrice": 5290 }, { "sku": "MT-1101-L", "price": 4590, "oldPrice": null } ] }
```

- `price` — цена поставщика, ₽. Акционная цена платформы пересчитывается от неё автоматически.
- `oldPrice` — зачёркнутая цена: число выше `price`, `null` — убрать; не передан — прежняя остаётся, если всё ещё выше новой.
- Ответ: `{ "received", "updated", "unchanged", "notFound": [sku], "errors": [{ "sku", "message" }] }`.

## Отправления

`GET /orders?status=<статус>&limit=<1…100>` — последние отправления, новые сверху.

`status`: `action` (по умолчанию — новые, подтверждённые и упакованные), `new`, `confirmed`, `packed`, `handed_over`,
`in_transit`, `ready_for_pickup`, `delivered`, `cancelled`, `rejected`, `all`.

```json
{
  "items": [{
    "id": "2f0c…", "number": "100045-1", "status": "new", "createdAt": "…", "paidAt": "…",
    "confirmBefore": "2026-10-29T12:00:00.000Z",
    "goodsTotal": 9180, "recipientName": "Анна Тестова",
    "delivery": { "type": "pvz", "tariffCode": 136, "cityCode": 137, "pvzCode": "SPB12", "address": "…", "trackNo": null },
    "items": [{ "sku": "MT-1101-M", "title": "Костюм «Хирург»", "size": "M", "heightRange": "170–176", "color": "Бирюзовый", "qty": 2, "price": 4590 }]
  }]
}
```

Телефон и email покупателя через API не отдаются — они видны в кабинете, пока заказ исполняется.
Неподтверждённое до `confirmBefore` отправление отменяется с возвратом денег.

`POST /orders/:id/confirm` — подтвердить новое отправление. Ответ `{ "id", "number", "status": "confirmed" }`;
статус уже другой — `409`. Упаковка, накладная СДЭК и печать — в кабинете («Заказы»).

## Ключи

- Не больше 5 действующих ключей; отзыв действует сразу.
- Храните ключ на сервере, не в браузере и не в репозитории. Утёк — отзовите и создайте новый.
- Сотрудники с ролями «Каталог» и «Склад» ключами не управляют.

## Другие способы

- YML-фид по расписанию — раздел «Импорт»: каждый 1, 6 или 24 ч, пауза; после 3 ошибок подряд синк встаёт на паузу и приходит уведомление.
- Файл XLSX/CSV по шаблону — там же, с проверкой перед применением.
