## Решения по умолчанию (до ответа на открытые вопросы ТЗ §14)

- Название в коде и интерфейсе — `aesculap` как в макете; вынесено в конфиг, чтобы сменить одной правкой.
- Анкета — как в макете (цветотип + фото); поле дресс-кода предусмотрено в схеме.
- Доставка остаётся платформе в сплите; комиссия по умолчанию 10%, настраивается на поставщика.
- Бейдж «Распродажа» до запуска акций (этап 5) ставится по наличию старой цены.
- В dev `STOREFRONT_REQUIRE_PAYOUTS=false`: витрина показывает товары поставщиков без подключённых выплат; в проде — `true` (ТЗ).
